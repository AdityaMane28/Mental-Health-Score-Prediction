# Mental Health Risk Prediction

An end-to-end machine-learning notebook that estimates a **survey-derived mental-health risk score (0–100)** and classifies respondents as **Low, Moderate, or High** using workplace, support, stigma, and background survey responses.

> **Scope:** This project is an educational screening prototype, not a clinical assessment or diagnosis. Its score is a proxy derived from survey responses, not a validated mental-health scale. It must not be used to make employment decisions.

## Project overview

The pipeline uses the 2014 Mental Health in Tech Survey (1,259 rows and 27 columns in the supplied file) to explore whether workplace and background factors can predict reported work interference and treatment seeking. It cleans inconsistent survey answers, encodes ordered responses, engineers a transparent proxy target, compares models, evaluates subgroup results, and saves fitted models.

The dataset contains information about work environment, employer support, stigma, treatment, family history, age, gender, and country. **It does not include stress level, sleep duration, or physical activity.** The notebook has optional encoders for those fields if they are added to a future dataset; its synthetic demonstration rows are not used to train or evaluate the current models.

## How the proxy targets are defined

The survey does not include a validated clinical scale such as PHQ-9, GAD-7, or PSS-10. The notebook creates this 0–100 proxy from two self-reported fields:

```text
risk_score = 100 × (0.6 × work_interfere / 4 + 0.4 × treatment)
```

`work_interfere` is encoded from None (0) through Often (4), and `treatment` is encoded as No (0) or Yes (1). The proxy score is grouped into Low (<30), Moderate (30–<70), and High (≥70) classes.

Those two fields define the target, so they are removed from the model inputs to prevent direct target leakage. The models use the remaining survey features to predict this proxy. Because treatment seeking is part of the target, predictions reflect reported care-seeking as well as reported work interference; they do not measure clinical severity.

## Notebook workflow

1. Load and audit the CSV, including types, missing values, and category counts.
2. Clean implausible ages, normalize gender and country categories, and handle missing survey answers.
3. Ordinal-encode ordered responses and one-hot encode gender and country.
4. Create the proxy score and three risk classes, then split the data 80/20 with class stratification.
5. Select features using mutual information, random-forest importance, and RFECV. Selection is performed on training data.
6. Compare and tune classification and regression pipelines using cross-validation.
7. Evaluate once on the held-out test set; inspect confusion matrices, permutation importance, and performance by age band and gender.
8. Demonstrate `predict_risk()` for new survey responses and save the selected models and metadata.

## Data source

The dataset is the OSMI (Open Sourcing Mental Illness) 2014 Mental Health in Tech Survey. Obtain the CSV from the [OSMI research page](https://www.osmihelp.org/research.html) or its [Kaggle dataset listing](https://www.kaggle.com/osmi/mental-health-in-tech-survey/data), and place it as `survey.csv` in the notebook's working directory. The supplied notebook searches for `survey.csv` in the current directory (and includes a hosted-notebook fallback path).

Review the license terms attached to the exact dataset copy you download, provide the required attribution, and follow any share-alike conditions before redistributing it. Avoid publishing any sensitive respondent information or free-text fields without checking the applicable terms and privacy requirements.

## Setup and run

Python 3.10 or newer is recommended.

```bash
# Create and activate a virtual environment
python -m venv .venv

# Windows PowerShell
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate

# Install dependencies
python -m pip install -r requirements.txt

# Start Jupyter and open the notebook
jupyter notebook mental_health_risk_pipeline.ipynb
```

Run notebook cells from top to bottom. The notebook performs cross-validation and grid search, so model-training cells may take longer than the data-cleaning and visualization cells. To score new records, provide the required non-target survey fields to the notebook's `predict_risk()` function; it returns a regression score, a classification level, class probabilities, and an illustrative suggested action.

## Limitations and responsible use

- **Not a clinical measure:** the engineered target is a proxy based on work interference and treatment history, not a diagnosis or validated symptom scale.
- **Moderate predictive performance:** the recorded test macro-F1 is 0.511 for classification and R² is 0.220 for regression. The model is uncertain, especially for the smaller Moderate class.
- **Historical, selected sample:** the 2014 technology-workplace respondents may not represent other industries, regions, or time periods. Revalidate on appropriate, current data before any use beyond learning or research.
- **Incomplete factors:** stress, sleep, and physical activity are absent from the supplied dataset.
- **Subgroup estimates are limited:** small subgroup sizes make gender and age comparisons noisy; the notebook reports group counts alongside metrics.
- **Privacy and consent:** mental-health survey data is sensitive. Limit access, minimize retention, obtain appropriate consent, and follow applicable data-protection rules.
- **Human oversight:** any real-world support should be voluntary, confidential, and reviewed by qualified people. Predictions should never be used to screen, rank, hire, promote, or discipline workers.
